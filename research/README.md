# Research

Two studies of the π0 vision-language-action model, both run in the Robotic Vision Laboratory at UT Arlington. The summer study follows directly from the spring one.

| Study | Question | Start here |
|---|---|---|
| [**Spring 2026: robustness on LIBERO-plus**](spring-robustness-study/README.md) | How does π0 degrade when the instruction, the scene, the camera or the robot start changes? | [`spring-robustness-study/README.md`](spring-robustness-study/README.md) |
| [**Summer 2026: failure analysis and object grounding**](summer-failure-analysis/README.md) | Does π0 find the instructed object, or go to a memorized place with a memorized motion? | [`summer-failure-analysis/reports/illustrated-report.md`](summer-failure-analysis/reports/illustrated-report.md) |

**How they connect.** Spring found that π0 survives moved *objects* but not a moved *robot start* or *camera*. Summer tested that suspicion directly with single-factor perturbations of the image, the robot's own state and the scene itself.

[`literature.md`](literature.md) lists the papers both studies build on.
